4. Mécanismes d'entrée

A. Pipeline Orders MCP

Poll /pending-order?symbol=... toutes les 3s. Le serveur envoie : action, prix, SL, TP, lot. Validé par :

  • IA ≠ HOLD, GOM ≠ WAIT
  • Pas de double-indécision IA+COG
  • Execution via SafeOrderSend

B. GOM Autonomous GOMPerfectAutoEntry

Déclenché quand GOM=PERFECT ou GOOD :

  • PERFECT → LIMIT sur S/R ou MARKET direct
  • GOOD → LIMIT sur zone OB (Kola ou BB mid)
  • SIMPLE → optionnel

C. Triple Aligné GOM+IA+COG

Quand les 3 signaux sont alignés dans la même direction :

  • Près d'un niveau OB/SR → LIMIT
  • Pullback EMA M5 détecté → MARKET
  • Bypasse les gates 10-15 du DecisionEngine

D. GOM Wait Pullback WAIT_PULLBACK

Si GOM=WAIT mais COG+IA alignés : places des LIMIT OB.

  • Nécessite confiance IA ≥ 55%
  • Mode défensif : entre seulement sur retracement

E. Gold Scalp GoldScalpEnabled

Ré-entrées agressives sur XAUUSD tant que COG=BUY + GOM≥2 :

  • Rebond EMA9 M1 ou touch OB Bullish M1
  • Max 3 scalps simultanés
  • Cooldown 120s entre ré-entrées
  • Fermeture si COG change ou GOM→WAIT

F. Entrées Legacy DecisionEngine=OFF

Ancien chemin via ValidateTradeBeforeExecution() :

  • Analyse MTF (2/3 TF alignés sur H4/H1/M15)
  • Zone correction, validation M1, post-spike
  • BC heure, probability gate

7. Gestion des pertes & performance

📈 Win Streak Pause

  • Seuil : WinStreakThreshold (5 gains consécutifs)
  • Action : Pause toutes les entrées pendant WinStreakPauseHours (2h)
  • Suivi : g_winStreakSessionUSD cumulé, persisté en GV

📉 Loss Streak Pause

  • Seuil : 2 pertes consécutives
  • Symboles différents : Pause GLOBALE 1h
  • Même symbole : Pause symbole 2h
  • Reset : Un gain remet le compteur à zéro

🛡 Profit Giveback Guard

  • Déclencheur : Drawdown depuis pic journalier > ProfitGivebackPct (40%)
  • Pic minimum : ProfitGivebackMinPeakUSD ($5.0)
  • Action : Pause 2h ou jusqu'à nouvelle journée

🔒 Petit Loss Block

  • Seuil : MinLossBeforeAutoCloseUSD ($3.0)
  • Comportement : Bloque la fermeture si perte < seuil
  • Exceptions : Force close ou GOM=WAIT

8. Market Intelligence

📊 Régime de marché

Détecté via ATR percentile + ADX :

  • Range : ATR < 25e percentile
  • Trend fort : ADX > 28
  • Volatilité extrême : ATR > 85e percentile
  • Squeeze : BB width analysis
  • Score de régime : 0-100 adapté à la direction

🔗 Filtre corrélation

Groupes définis par nom de symbole :

  • 10 groupes : EUR, USD, GBP, AUD, METAL, CRYPTO, INDEX, OIL, BC, NONE
  • Limite : ExtMaxPerGroup (1) position max par groupe
  • Couvre les corrélations directes ET inverses

⏰ Qualité de session

Scores de qualité par heure UTC pour chaque catégorie :

  • London AM (8-11h) : score élevé pour Forex, Métaux
  • NY Open (13-16h) : score élevé pour Indices, Crypto
  • Asia (0-6h) : score faible sauf Crypto
  • Minimum : ExtMinSessionQuality (50.0)

📐 MTF Alignment

Score d'alignement multi-timeframe (0-100) :

  • H4 : Prix par rapport à EMA50
  • H1 : Pente EMA21
  • M15 : RSI(14) zone
  • Moyenne des 3 scores = mtfScore

9. God Mode — Master Score (0-100)

Fusionne 8 composants pondérés en un score unique. Le trade est refusé si score < ExtMasterScoreMin (85). PERFECT bypass : si GOM=PERFECT, le master score peut être ignoré.
